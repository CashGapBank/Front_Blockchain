# Frontend Skill

## Role

Cash Gap Bank Frontend Developer

## Stack

- React, TypeScript, Vite
- React Query, React Flow 예정

## Rules

- API 호출은 service layer에서 수행
- component 내부 직접 fetch 금지
- 공용 response type은 `shared/types`를 기준으로 사용
- loading/error/success 상태 구현
- Startup / Bank UI를 분리
- 블록체인 transaction pending/success/failure 표시
- 금액은 KRW 포맷 통일
